# Инструктаж для ИИ-агента

Ты работаешь с системой автомонтажа на Remotion. Этот файл — твой контракт: следуй ему,
а не общим привычкам.

## Первое действие

Прочитай README.md целиком. Порядок работы — там, здесь — то, что агенты обычно ломают.

## Железные правила

1. **Один файл правды — `edit-plan.json`.** Монтаж правится только в нём. Не хардкодь
   тайминги, тексты и координаты в компонентах: код читает лист, и это устройство системы.

2. **Тайминги — секунды от начала ИСХОДНИКА.** Всегда, во всех разделах, даже после
   вырезания пауз. Пересчёт выходного времени делает `src/trim.ts` — не дублируй его
   логику и не «помогай» ей.

3. **Версии Remotion — все одинаковые, с точным пином.** Ставя любой пакет `@remotion/*`,
   бери ту же версию, что у `remotion` в package.json проекта, с флагом `--save-exact`.
   Обновление — всех разом: `npx remotion upgrade`. Проверка: `npx remotion versions`
   должна кончаться «All packages have the correct version».

4. **Не выдумывай пропсы и флаги.** Перед использованием API читай типы в
   `node_modules/<пакет>/dist/*.d.ts`. Известная ловушка: у rough-notation проп
   называется `progress`, не `animationProgress`; у OffthreadVideo актуальны
   `trimBefore`/`trimAfter`, а `startFrom`/`endAt` устарели.

5. **Проверяй делом, не чтением.** После правок: `npx tsc --noEmit`, затем `npm run check`,
   затем один кадр `npx remotion still ... --frame=N` — и только потом полный рендер.
   Кадр рендерится секунды, полный проход — минуты: лови ошибки на кадре.

6. **Ничего не публикуй и не отправляй.** Готовый файл отдай человеку. Решение о публикации
   принимает он.

7. **Не хватает инструмента — доустанови, а не сдавайся.** Сначала диагноз:
   `node tools/проверить-окружение.mjs` (в репозитории — `инструменты/`). Потом установка
   по подсказкам проверки, под ОС этой машины и с согласия человека. Ставится версия,
   которая встаёт на эту машину; встала старая — проверь её делом: для whisper прогони
   короткий кусок и убедись, что выход — пословный JSON с таймингами на каждое слово.
   Без этого не работают только субтитры и смысловой разбор — рендер, паузы и крупность
   живут и так; скажи об этом человеку честно, а не молчи.

## Агентский конвейер

Развёртывание кладёт в проект плейбуки конвейера (`.claude/agents/`: genre-picker,
dramaturg, plan-marker) и канон (`монтажёр/жанры.json`, `монтажёр/правила-текста.md`).
Формат плейбуков двойной: Claude Code подхватит их как субагентов сам, любой другой
агент читает те же файлы как обычные инструкции — фронтматтер сверху игнорируй. Порядок: паспорт →
транскрипт → genre-picker (жанр и формат; несовпадение ориентации = стоп и вопрос
человеку) → dramaturg (структура, выводы, смысловые вырезы, паузы-акценты) → твои
решения по развилкам → plan-marker (валидный лист, зелёный check). Эскизы стилей —
`node tools/эскизы.mjs --from <сек> --to <сек>`: три варианта фрагмента на выбор человеку.
Контракты выходов агентов: ключи латиницей, обоснования в поле `note`.
Нет субагентов у твоего хоста — пройди те же шаги сам по этим файлам, по одному за раз:
каждый плейбук самодостаточен.

## Конвейер одной картинкой

```
запись.mp4
  → развернуть-проект.sh                (шаблон + шрифт + звуки + зависимости)
  → whisper-cli -ml 1 -sow -oj         (пословный JSON; без -sow слова рублены)
  → node tools/субтитры-из-whisper.mjs (раздел subtitles)
  → руками или через агентов: cues     (надписи-выводы, главный слой)
  → node tools/вырезать-паузы.mjs      (раздел trims + панч-ин)
  → npm run check                       (чеклист до рендера)
  → npx remotion still …                (контрольные кадры)
  → npm run render
```

## Что где лежит

| Файл | Ответственность |
|---|---|
| `src/trim.ts` | пересчёт времени после вырезов — единственное место этой логики |
| `src/Fragment.tsx` | сборка слоёв: сегменты видео, крупность, субтитры, надписи, звук |
| `src/Sounds.tsx` | автозвук из листа: свитч на вывод, whip на склейку `cut: true` |
| `src/Highlight.tsx` | надпись-вывод; обводка считается от кегля |
| `src/Subtitles.tsx` | караоке; гаснет, когда в кадре вывод |
| `src/Zoom.tsx` | крупность по ключам; `cut: true` — скачок |
| `tools/проверка-листа.mjs` | чеклист листа; гоняй перед каждым рендером |
| `tools/проверить-окружение.mjs` | что стоит на машине, чего не хватает и как поставить |
| `монтажёр/правила-текста.md` | канон надписей: четыре типа ценности, форма, крупность |

## Грабли, уже оплаченные

- **Паузы ищи в звуке, не в транскрипте**: whisper растягивает конец слова до начала
  следующего — пауз в его таймингах не существует.
- **К встроенному ffmpeg добавляй `-vn` при анализе звука**: в урезанной сборке нет
  кодировщика для нулевого видео-потока, без `-vn` падает «Encoder not found».
- **ID композиций — латиница и цифры**; пути внутри `public/` — латиницей.
- **Шрифт не грузи из сети на рендере** — файлы лежат в `public/fonts/`, схема подключения
  в `src/font.ts`; конструктор `FontFace` под нагрузкой отваливается, не возвращайся к нему.
- **Чёрный кадр на стыке сегментов** — болезнь превью, не рендера; в студии лечится
  `premountFor`, уже стоит.
- **Звуки — только локальные** из `public/sounds/`; URL из `@remotion/sfx` на рендере —
  сеть в цикле, любой сбой роняет проход.

## Если что-то не так

Сломался рендер — читай ошибку целиком, найди её в «граблях» выше и в README раздела
«Порядок работы». Не переустанавливай всё подряд, пока не поставлен диагноз. Правку делай
одну за раз и после каждой — `npm run check`.
