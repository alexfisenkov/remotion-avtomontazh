# Скиллы для ИИ-агентов

Скилл — это плейбук, который агент подхватывает сам, когда задача подходит под его описание.
Здесь лежит один скилл — «сделай-монтаж»: он ведёт весь конвейер от записи до готового ролика.

## Установка

**Важно про сам репозиторий:** клон — не разовый установщик, а постоянный актив:
конвейер обращается к нему при каждом монтаже (скрипт развёртывания, инструменты,
агенты, звуки). Клонируйте в постоянное место и не удаляйте; канонический путь,
который скилл ждёт по умолчанию — `~/remotion-avtomontazh`:

```bash
git clone https://github.com/alexfisenkov/remotion-avtomontazh.git ~/remotion-avtomontazh
```

**Claude Code:** скопируйте папку скилла в свои скиллы —

```bash
mkdir -p ~/.claude/skills
cp -r ~/remotion-avtomontazh/скиллы/сделай-монтаж ~/.claude/skills/
```

Проверка: в новой сессии Claude Code скажите «сделай монтаж» и дайте путь к записи —
скилл должен подхватиться сам.

**Codex и другие агенты:** дайте агенту прочитать `скиллы/сделай-монтаж/SKILL.md` как
инструкцию к задаче — это обычный текст, привязки к конкретному агенту в нём нет.

Скилл рассчитан на работу из папки проекта, развёрнутого `./развернуть-проект.sh` —
там уже лежат агенты конвейера, инструменты и канон жанров.
