# Сделай монтаж

Один вход — путь к записи. Один выход — готовый ролик, прошедший критику. Всё между ними —
конвейер из кода и агентов, где творческие решения принимает мозг (эта сессия), механику
делают узкие агенты, а повторяемое давно лежит в инструментах.

Канон конвейера — README репозитория remotion-avtomontazh (раздел «Порядок работы» и
AGENTS.md); этот скилл — его исполняемая форма. Расхождение скилла с каноном — баг:
чините оба вместе, а не молча одно из двух.

## Предпосылки

Репозиторий remotion-avtomontazh — постоянный актив конвейера; путь по умолчанию —
`"$HOME/remotion-avtomontazh"`. Репозиторий уже стоит — сначала обновите его:
`git pull` в этой папке (система дорабатывается, вчерашний клон мог устареть).
Нет его там — склонируйте сами, человека не спрашивайте:
`git clone https://github.com/alexfisenkov/remotion-avtomontazh.git "$HOME/remotion-avtomontazh"`
(нет git на macOS — скачайте ZIP с codeload.github.com, чтобы не будить диалог Command
Line Tools; на Windows git ставится `winget install --id Git.Git -e`). Проект
разворачивается командой
`node "$HOME/remotion-avtomontazh/развернуть-проект.mjs" <папка> <видео>` — она кладёт в папку выпуска агентов конвейера
(`.claude/agents/` — читаются любым агентом как плейбуки), канон жанров и текста
(`монтажёр/`), инструменты (`tools/`) и звуки.
Работайте из папки выпуска. whisper и модель — раздел «Транскрипт» README репозитория.

**Окружение — проверить и доустановить.** Первым делом:

```bash
node ~/remotion-avtomontazh/инструменты/проверить-окружение.mjs
```

Чего-то не хватает — доустановите САМИ, человека не просите и команд ему не показывайте:

```bash
node "$HOME/remotion-avtomontazh/инструменты/установить-окружение.mjs"
```

Он ставит whisper, ffmpeg, python и Pillow под ОС машины. Единственный вопрос человеку —
согласие скачать модель (~1,6 ГБ): формулировку печатает сам установщик, задайте её
дословно и передайте ответ флагом `--модель large` или `--модель small` (слабая машина
или мало диска — `small`, 0,5 ГБ; конвейер тот же). Перед первой установкой предупредите
человека одной фразой про чёрное окно с бегущими строками — это нормальный вид установки.
Если whisper встал старый или собран иначе — не верьте на слово: прогоните его на
коротком куске записи и проверьте выход делом (JSON, одна запись на слово, у каждого
слова свои тайминги). Флаги `-ml 1 -sow` не поддерживаются — подберите эквивалент или
новее сборку, но без пословного JSON дальше не идите.

## Конвейер

Артефакты между шагами — файлами, не пересказом. Папка выпуска — `выпуск-ГГГГ-ММ-ДД/`
в проекте (или где скажет человек; имя латиницей, если внутри будут пути для бандлера).

### 1. Паспорт — код

```bash
node tools/паспорт-исходника.mjs <видео> паспорт.json   # из папки выпуска
```

Формат, ориентация, fps, длительность, LUFS, паузы. Без паспорта дальше не ходить:
боль «элементы криво легли» рождается ровно здесь.

### 2. Транскрипт — код

```bash
npx remotion ffmpeg -i <видео> -ar 16000 -ac 1 audio16.wav -y   # из любого проекта Remotion
whisper-cli -m <модель> -l ru -np -ml 1 -sow -oj -of слова audio16.wav
```

`-ml 1 -sow` обязательны: без них русские слова приезжают кусками BPE.

### 3. Жанр — агент genre-picker (sonnet)

Вход: паспорт, транскрипт, пожелание человека (если было). Выход: JSON с жанром, форматом,
несовпадениями. **Несовпадение ориентации с профилем — стоп и вопрос человеку**, это не
предупреждение. Ключи выхода латиницей, обоснование в `note` (поле `reasoning` в схемах структурного выхода режут сейфгарды моделей — используйте `note`).

### 4. Развёртывание — код

```bash
node "$HOME/remotion-avtomontazh/развернуть-проект.mjs" <папка-выпуска> <видео>
```

Сам подставит формат, отмасштабирует геометрию (вертикали — профиль канона), положит
звуки, шрифт, агентов и инструменты. Если выпуск уже развёрнут (шаг 1 делался из него) —
шаг пропускается. Паспорт до развёртывания снимается из репозитория:
`node ~/remotion-avtomontazh/инструменты/паспорт-исходника.mjs <видео> паспорт.json`.

### 5. Смысловой разбор — агент dramaturg (модель сессии)

Вход: транскрипт, решение жанриста. Выход: структура, кандидаты в выводы, смысловые вырезы
с честным «что теряется», паузы-акценты, кульминация. Драматург решает ЧТО — не КАК.

### 6. Утверждение — мозг ± человек

Решения по развилкам драматурга принимает оркестратор и записывает списком: что принято,
что отклонено и почему. Спорное — вопросом человеку (есть у хоста инструмент вопросов с вариантами — им,
нет — обычным вопросом в чате). Если человек не задал
оформление — **эскизы**:

```bash
cd <выпуск> && node tools/эскизы.mjs --from <сек> --to <сек>   # обычно вокруг кульминации
```

Три варианта фрагмента (сдержанный / полный / чистовик) за минуту — показать, дать выбрать.
Выбор варианта = раздел `layers` листа; правится данными, не кодом.

### 7. Разметка — агент plan-marker (sonnet)

Вход: решения драматурга + вердикты оркестратора + папка выпуска. Выход: валидный лист,
зелёный `npm run check`, отчёт с конфликтами (если были — вернуть на шаг 6, не решать за него).

### 8. Музыка — по жанру и желанию

Жанровый профиль подсказывает дефолт (`слои.музыка` в жанрах: у вертикали включена),
решает человек. Раздел `music` листа: `{"file": "pad-calm.wav", "volume": 0.07}` — пэд
кладётся в `public/music/` при развёртывании; свой трек человек кладёт туда же. Уровни
и правила — README библиотеки звуков, раздел «Музыка».

### 9. Рендер и приёмка — код + критики

Кадры до полного прохода (`npx remotion still` на каждой надписи с неочевидной геометрией),
затем `npm run render`, затем `ffprobe` на длительность и звук. Дальше — проверка содержания: сверьте каждую надпись с транскриптом (не обещает ли
больше сказанного), просмотрите кадры на каждой надписи, убедитесь, что в кадр не попало
приватное. Если у вашего агента есть свои агенты-критики — прогоните и через них.

## Правила оркестратора

- Решения — мозгу, механика — агентам, повторяемое — коду. Не делайте руками то, на что
  есть агент: контекст сессии дороже.
- Агент вернул конфликт — решает мозг или человек, не агент.
- Каждое «готово» проверяйте запуском: чеклист, кадр, вычет дорожек. Слова агентов — не факт.

## Чего конвейер пока не делает

Честный список, чтобы не обещать лишнего: b-roll и перебивки; склейка по морганию;
подбор чужой музыки (только свой пэд или трек человека); классический дакинг — музыка
держится постоянным уровнем «под речью», а не приглушается под фразами; автопостинг. Просят это —
скажите прямо, что шага нет, и предложите ручной путь.
