# Автомонтаж на Remotion

Готовая система монтажа говорящей головы: агент вырезает паузы, ставит субтитры-караоке
под голос, выносит главные мысли надписями, двигает крупность и расставляет звуковые
акценты. Собрано для учеников курса Александра Фисенкова, работает с любым ИИ-агентом:
Claude Code, Codex, Cursor, Gemini CLI и другими.

## Как получить смонтированное видео — три шага

Ставить самим ничего не нужно — ни программ, ни дополнений. Всё делает ваш ИИ-агент.

1. **Скопируйте адрес этой страницы** из адресной строки браузера.

2. **Отправьте своему агенту** (Claude Code или Codex) вот это сообщение целиком:

   > Установи систему автомонтажа из репозитория
   > https://github.com/alexfisenkov/remotion-avtomontazh — склонируй его в
   > "$HOME/remotion-avtomontazh", поставь скилл «сделай монтаж» и сам доустанови
   > всё недостающее: Node.js, whisper с офлайн-моделью, ffmpeg, python — как
   > написано в AGENTS.md репозитория. Ничего не проси меня устанавливать руками,
   > технические вопросы решай сам. Когда всё готово и проверено — напиши:
   > «готов к монтажу».

3. **Когда агент напишет «готов к монтажу»** — отправьте ему: «Сделай монтаж» и
   укажите, где лежит ваша запись (можно перетащить файл прямо в окно агента).
   Дальше он будет спрашивать только про смысл: жанр, стиль, что вынести на экран.

Два спокойных замечания:

- **Чёрное окно с бегущими строками** во время установки — это нормально: так агент
  ставит инструменты, компьютер не ломается. На Windows появится вопрос «Разрешить
  этому приложению вносить изменения?» — ответьте «Да».
- **Один раз агент спросит разрешение скачать словарь распознавания речи** (~1,6 ГБ).
  Это единственная большая закачка: дальше субтитры работают без интернета.

# Для агента

Система описывается одним файлом `edit-plan.json`, рендерится одной командой и
правится без пересборки видео руками. Твой контракт — `AGENTS.md`; здесь — устройство
и порядок работы.

## Что внутри

| Папка | Что это |
|---|---|
| `шаблон/` | проект Remotion: компоненты всех слоёв + монтажный лист-заготовка |
| `инструменты/` | скрипты конвейера: субтитры, вырезание пауз, проверка листа, разметка сплита |
| `звуки/` | правила звука, манифест с паспортами 40 звуков, наши синтезированные файлы и загрузчик остальных |
| `агенты/` | субагенты конвейера для ИИ-агентов (копируются в проект при развёртывании) |
| `монтажёр/` | канон жанров и профилей (урок, промо, вертикаль, чистовик) и правила текста надписей |
| `скиллы/` | скилл «сделай-монтаж» для любого ИИ-агента: весь конвейер одной командой (установка — скиллы/README.md) |
| `развернуть-проект.mjs` | одна команда — и проект готов к разметке (на любой ОС) |

## Что нужно системе (агент, это ставишь ты)

- **Node.js 20 или новее** — весь конвейер. Нет или старый: `brew install node` /
  `winget install --id OpenJS.NodeJS.LTS -e`. Человека на nodejs.org не отправляй.
- **git** — для клона. Нет на macOS — НЕ вызывай его (первый вызов будит GUI-диалог
  Command Line Tools на гигабайты): возьми ZIP с
  `https://codeload.github.com/alexfisenkov/remotion-avtomontazh/zip/refs/heads/main`.
  На Windows: `winget install --id Git.Git -e`.
- **whisper + модель, системный ffmpeg, python, Pillow** — одной командой:
  `node инструменты/установить-окружение.mjs`. Она детерминированно ставит всё под
  текущую ОС; про модель печатает вопрос, который ты дословно задаёшь человеку.
- **Запись** — говорящая голова, любой mp4/mov. Камера на весь кадр или сплит со скринкастом.

Диагноз до и после — `node инструменты/проверить-окружение.mjs`
(ненулевой код выхода = чего-то не хватает).

## Быстрый старт

```bash
git clone https://github.com/alexfisenkov/remotion-avtomontazh.git "$HOME/remotion-avtomontazh"
cd "$HOME/remotion-avtomontazh"
node инструменты/проверить-окружение.mjs        # диагноз
node инструменты/установить-окружение.mjs       # доустановка недостающего
node развернуть-проект.mjs "$HOME/video/moy-vypusk" /путь/к/записи.mp4
cd "$HOME/video/moy-vypusk"
npm run studio
```

Пути в командах — через `"$HOME"`, не через `~`: PowerShell не раскрывает `~` в
аргументах программ, и git создал бы папку с буквальным именем `~`.

Скрипт скачает шрифт Oswald (Google Fonts, лицензия OFL) и базовые звуки с сервера Remotion,
скопирует шаблон, поставит зависимости и подставит длительность записи в монтажный лист.

Папка проекта — латиницей без пробелов: имя становится именем npm-пакета, а пути внутри
`public/` читает бандлер.

## Что куда класть

Короткая карта, чтобы ничего не искать:

| Что у вас есть | Куда положить |
|---|---|
| клон этого репозитория | постоянное место, канонично `~/remotion-avtomontazh` — конвейер обращается к нему при каждом монтаже, не удаляйте после установки скилла |
| исходная запись (mp4/mov) | куда угодно — путь передаётся команде развёртывания, копия ляжет в `public/clips/full.mp4` сама |
| модель whisper (`ggml-*.bin`) | куда угодно, например рядом с проектами; путь передаётся whisper-cli флагом `-m` |
| свой музыкальный трек | `public/music/` папки выпуска; имя файла — в раздел `music` листа |
| свои звуки-эффекты | `public/sounds/` папки выпуска; правила громкости — `звуки/ПРАВИЛА.md` |
| свой шрифт вместо Oswald | `public/fonts/` + правка `src/font.ts`; имена файлов — латиницей |
| скилл для вашего ИИ-агента | одной командой под все агенты сразу — `скиллы/README.md` |

Всё остальное (агенты, инструменты, звуки базы, шрифт, пэд) раскладывает
`развернуть-проект.mjs` — руками ничего носить не надо.

## Как пользоваться: два пути

**С ИИ-агентом (рекомендуемый).** Поставьте скилл под своего агента (`скиллы/README.md`),
откройте агента в папке развёрнутого выпуска и скажите «сделай монтаж» с путём к записи.
Агент проведёт конвейер сам: проверит окружение и предложит доустановить недостающее
под вашу систему, определит жанр и формат, разберёт смысл, покажет эскизы стилей на
выбор, разметит лист и отрендерит. Ваши решения он спросит в развилках.

**Руками.** Идите по «Порядку работы» ниже шаг за шагом — каждый шаг это одна команда
или правка одного файла `edit-plan.json`.

## Порядок работы

Всё правится в одном файле — `edit-plan.json`. Код только читает его.
**Тайминги везде — секунды от начала исходной записи**, даже после вырезания пауз:
пересчёт выходного времени делает `src/trim.ts`, и только он.

### 1. Транскрипт с пословными таймингами

```bash
# звук для whisper: WAV 16 кГц, моно — готовится встроенным ffmpeg
npx remotion ffmpeg -i public/clips/full.mp4 -ar 16000 -ac 1 audio16.wav -y

# одна запись на слово: -ml 1 -sow обязательны, без них русские слова приезжают кусками
whisper-cli -m "$HOME/whisper-models/ggml-large-v3-turbo.bin" -l ru -np -ml 1 -sow -oj -of words audio16.wav
```

Имя выходного файла — латиницей (`-of words`): whisper-cli.exe на Windows пишет файл
через ANSI-API, и кириллическое имя может искалечиться.

Движок и модель ставит `инструменты/установить-окружение.mjs`: whisper — через brew на
macOS и готовыми официальными бинарниками из релизов на Windows/Linux (сборка через
cmake НЕ нужна; ассеты лежат в релизах вида `b4938`, у тегов вида `v1.9.3` ассетов нет).
Модель — прямым curl без каких-либо установок:

```bash
mkdir -p "$HOME/whisper-models" && cd "$HOME/whisper-models"
curl -L -C - -o ggml-large-v3-turbo.bin \
  "https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin"
```

Каноническое место модели — `"$HOME/whisper-models"`: там её ищет проверка окружения.
Подлинность = размер ровно 1 624 555 275 байт. Для русской речи выбор — `large-v3-turbo`;
слабая машина или мало диска — `ggml-small.bin` (487 601 967 байт): качество ниже,
конвейер тот же. `medium` не берите: весит как turbo, а работает медленнее.

**huggingface.co из сети не открывается** (в России это обычное дело) — тот же путь
через зеркало `https://hf-mirror.com/…` (проверено 24.08.2026: зеркало отвечало
редиректом 308 обратно на huggingface.co — может не спасти). Не прошло — ищите живой
источник сами; критерий подлинности один: размер до байта.

### 2. Субтитры-караоке

```bash
node tools/субтитры-из-whisper.mjs words.json
```

Кладёт раздел `subtitles` в лист: строки до 26 символов, разрыв по концу фразы и паузе
больше 0,6 с. Слово под голосом подсвечивается жёлтым. При появлении надписи-вывода
субтитры гаснут сами: две надписи в кадре конкурируют, и зритель не читает ни одну.

### 3. Надписи-выводы

Заполняются руками в `cues` — это главный слой. Правила коротко: 2–5 слов, максимум две
строки, минимум 1,6 с на экране, пауза между надписями от 1,5 с, вход за 2 кадра до
ключевого слова, жёлтым — ровно одно слово или связка. Надпись — вывод, который человек
унесёт с собой при просмотре без звука, а не пересказ речи. Полный канон — что выносить,
форма, точность к речи — [монтажёр/правила-текста.md](монтажёр/правила-текста.md).

### 4. Вырезание пауз

```bash
node tools/вырезать-паузы.mjs
```

Ищет паузы в самом звуке (порог −30 дБ, от 0,5 с) — по транскрипту их не найти: whisper
растягивает конец слова до начала следующего. Пишет в лист раздел `trims` — оставляемые
сегменты. Паддинги несимметричные: 0,15 с хвосту слова, 0,10 с атаке следующего.
Вырез, задевающий надпись, пропускается — пауза с выводом важнее сжатия. Если крупность
не размечена руками, на каждую склейку ставится панч-ин ±7% скачком — правило маскировки:
после выреза меняется хотя бы один параметр кадра.

Паузы-акценты (перед пуантом, после вопроса) автоматика от смысловых не отличает —
просмотрите `trims` и верните нужные паузы, расширив сегменты.

### 4а. Записи со сплитом (дополнительно)

Если в записи есть сплит (камера + скринкаст телефона), сначала разметьте режимы —
где какой кадр. Границы ищутся яркостью области, а не просмотром:

```bash
python3 tools/сцены-по-области.py public/clips/full.mp4 --rect 600,960,1300,110 --fps 2
```

Результат — в раздел `modes` листа. Приватное на скринкасте ищется контрольным листом
(`tools/контрольный-лист.py`, нужен Pillow) и закрывается блюром через `effects`.
Обоим скриптам нужен **системный ffmpeg** (`brew install ffmpeg` / `winget install ffmpeg` /
`apt install ffmpeg`) — встроенный в Remotion для них недоступен.

### 5. Крупность

Раздел `zoom`: ключи `{at, scale}`, между ними плавный переход с замедлением на выходе.
Канон: **шаг 6–10 пунктов, наездов подряд не больше трёх**, точка масштаба `50% 38%` —
глаза остаются в верхней трети. Полностью — в [монтажёр/правила-текста.md](монтажёр/правила-текста.md). Ключ с `cut: true` — резкая склейка: масштаб прыгает
за кадр, и на неё автоматически ставится звук whip.

### 6. Звук

Руками звуки не расставляются — `src/Sounds.tsx` выводит их из листа: свитч на появление
каждого вывода, whip на каждую резкую склейку. Остальные соответствия включаются полем
`тип` у надписи: `скриншот` → шатер, `успех` → дзынь, `ошибка` → мягкий тон, `уведомление`,
`пометка` → карандаш, `акцент` → vine-boom. Опечатку в типе ловит `npm run check`. Полные правила — какой звук к какому приёму,
громкости, тайминг — в [звуки/ПРАВИЛА.md](звуки/ПРАВИЛА.md). Главные запреты: плавный наезд
не озвучивается никогда; один звук в один момент; не класть звук на слово, которое зритель
должен разобрать.

### 6а. Музыка (по желанию)

Раздел `music` листа: `{"file": "pad-calm.wav", "volume": 0.07}` — файл из `public/music/`
(наш пэд кладётся туда при развёртывании; свой трек положите сами). Уровень 0.07 ≈ на 22 дБ
тише голоса — канон в [звуки/ПРАВИЛА.md](звуки/ПРАВИЛА.md), раздел «Музыка».

### 7. Проверка и рендер

```bash
npm run check      # чеклист: длительности, паузы, ширина строк, канон крупности, вырезы
npx remotion still src/index.ts Full out/проба.png --frame=300   # кадр — за секунды
npm run render     # всё видео
```

Сначала кадры, потом рендер: любую надпись с неочевидной геометрией смотрите на `still`.
После рендера проверьте звук и длительность: `npx remotion ffprobe out/готово.mp4`.

## Звуки: что откуда

Принцип: **чужое качаем у хозяев, своё держим здесь**.

- **32 базовых звука** принадлежат Remotion и в репозитории не лежат — их скачивает
  `звуки/скачать-базу.mjs` с remotion.media (развернуть-проект.sh делает это сам).
- **8 синтезированных** — наши, лежат в `звуки/sounds/`, лицензия CC0: райзеры трёх длин,
  мягкий поп, тик, спокойная ошибка, карандаш, мягкий свист. Генератор —
  `звуки/синтез-звуков.sh` (нужен sox), каждый звук воспроизводим командой.
- **Паспорта всех 40** — в `звуки/манифест.json`: длительность, пик, характер атаки
  («удар» ставится на событие, «нарастание» должно кончаться на событии).

Хотите больше — проверенные источники со свободной лицензией, откуда файлы можно класть
даже в публичные проекты:

| Источник | Лицензия | Что брать |
|---|---|---|
| [kenney.nl](https://kenney.nl/assets?q=audio) | CC0 | UI Audio, Interface Sounds, Impact Sounds, Sci-fi Sounds |
| [freesound.org](https://freesound.org) | фильтровать по CC0 | карандаш, тики, специфика; нужен бесплатный аккаунт |
| [opengameart.org](https://opengameart.org) | брать помеченное CC0 | подборки UI-звуков |

Pixabay, Mixkit, Zapsplat, Sonniss, BBC — **не годятся** для раздачи файлов: их лицензии
разрешают использование в видео, но запрещают распространение самих файлов.

## Откуда взялись правила

Пороги вырезания пауз, соответствия «приём → звук», громкости и тайминги собраны из
практики монтажа (TimeBolt, auto-editor, Descript, разборы монтажёров) и проверены на
живых рендерах. Канон и обоснования — [звуки/ПРАВИЛА.md](звуки/ПРАВИЛА.md); это снапшот
рабочей системы автора от 19 августа 2026.
